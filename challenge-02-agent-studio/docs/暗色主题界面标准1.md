# 暗色主题界面标准 1 / Dark Theme UI Standard v1.0

> **Standard Scope & Positioning / 标准定位**
> Built upon the unified Mindverse dark visual system, the Inter 18pt Medium typographic hierarchy, and the core Image Node design texture. This document establishes the standardized UI design and engineering specifications for console dashboards, settings modals, management drawers, and workflow cards across the entire application ecosystem.
> （基于 Mindverse 统一暗色系视觉规范、Inter 18pt Medium 字体体系以及 Image 核心节点设计质感，面向全系统控制台、设置弹窗、管理面板与流程卡片的标准化 UI 设计与工程实现规范。）

---

## 1. Core Design Principles / 核心设计原则

### 1.1 Layered Submersion & Spatial Reduction (层级沉浸与空间减法)
- **English**: Reject harsh, high-contrast pure black/pure white modes in favor of low-glare, high-tactile deep neutral grey gradients. Structure visual depth and spatial hierarchies through nuanced luminosity stepping (`#1f1f1f` $\to$ `#242424` $\to$ `#2d2d2d` $\to$ `#383838`) paired with ultra-thin hairline borders (`0.5px` – `1.0px`), rather than heavy drop shadows.
- **中文说明**：放弃刺眼的高对比度纯黑纯白模式，采用低眩光、高质感的深灰阶梯层次。依靠轻微明度递进（`#1f1f1f` $\to$ `#242424` $\to$ `#2d2d2d` $\to$ `#383838`）以及细微描边（`0.5px` ~ `1px`）构建层次与纵深，而非大面积强烈阴影。

### 1.2 Precision Contours & Material Consistency (精细轮廓与材质一致性)
- **English**: Strictly adhere to the **concentric stepped border-radius scale** (Outer Radius $\ge$ Inner Radius). Eliminate sharp raw corners and disjointed excessive radiuses. Utilize semi-transparent neutral borders (`#6b6b6b` / `#555555`) to produce a refined, anodized aluminum/precision instrument edge finish across dark surfaces.
- **中文说明**：严格遵循**分层递进圆角规范**（外层圆角 $\ge$ 内层圆角），杜绝尖锐生硬的直角或突兀的过大圆角。边框采用高半透明中性灰描边（`#6b6b6b`/`#555`），在暗底上呈现类似微磨砂阳极氧化铝/精密仪器的金属收边质感。

### 1.3 Monochrome Neutral Contrast & Controlled Highlights (纯粹黑灰中性色与克制高亮)
- **English**: Adopt a clean, distraction-free monochrome dark palette without artificial decorative theme accent colors. Interactive elements rely on high-contrast crisp white (`#FFFFFF`) / light grey (`#DEDEDE`) against dark neutral surfaces (`#242424` / `#2D2D2D` / `#383838`) paired with subtle borders (`#555555` / `#6B6B6B`).
- **中文说明**：全面采用纯粹、无干扰的黑灰白中性色阶，不加入额外人工装饰性主题色。交互与按钮依靠高对比的纯白（`#FFFFFF`）/ 浅灰（`#DEDEDE`）与深灰底色（`#242424` / `#2D2D2D` / `#383838`）及精密描边（`#555555` / `#6B6B6B`）建立清晰质感。

### 1.4 Typography Inheritance & Rhythmic Spacing (字体层级与排版呼吸感)
- **English**: Exclusively inherit the **Inter 18pt Medium** font family, anchored at weight `500` (Medium) as the core baseline and `600` (SemiBold) for structural headers. Maintain an 8-point rhythmic spacing scale (4px / 8px / 12px / 16px / 20px / 24px / 32px) to preserve consistent vertical cadences in forms and panels.
- **中文说明**：全面继承 **Inter 18pt Medium** 字体族，字重以 `500`（Medium）为中枢基准，辅以 `600`（SemiBold）强调。采用标准网格间距（4px / 8px / 12px / 16px / 20px / 24px / 32px），表单与卡片保持清晰的垂直韵律。

## 4. Geometric Form & Border Radius Scale / 几何形态与圆角梯度标准

All interfaces must strictly follow the **concentric nested border radius progression** (同心嵌套与尺寸自适应原则):

| Radius Level (圆角层级) | Value (圆角数值) | Tailwind Class | Specifications & Applied Context / 应用组件与规范要求 |
| :--- | :--- | :--- | :--- |
| **Outer Shell (外壳层)** | `20px` | `rounded-[20px]` | **Modal outer containers, primary canvas nodes (Image Node layout)**<br/>模态弹窗外壳容器、核心流程卡片外层 |
| **Inner Card (中卡片层)** | `14px` | `rounded-[14px]` | **Secondary configuration panels, guide containers, info blocks**<br/>次级配置卡片、功能说明卡、下拉大面板 |
| **Control / Nav (控件层)** | `10px` | `rounded-[10px]` | **Text inputs, textareas, select inputs, sidebar nav items**<br/>单行文本框、多行文本框、下拉选择器、侧边栏导航条目 |
| **Secondary Button (次按钮)**| `8px` | `rounded-[8px]` | **Secondary outline buttons, action chips (e.g. `Cookie preferences`)**<br/>次级线框按钮、独立小操作项 |
| **Pill / Capsule (胶囊层)** | `9999px` | `rounded-full` | **Primary action buttons (`Save changes`), toggle switches, avatars**<br/>主保存按钮、Toggle 开关组件、圆形头像容器 |

## 七、 页面与弹窗落地 Checklist

在开发或重构暗色主题界面时，必须对照以下检查项完成审查：

1. **字体继承验证**：
   - [ ] 根容器或当前模块是否包含 `font-inter [font-family:var(--font-inter)]`？
   - [ ] 字重是否使用 `font-medium` (500) 或 `font-semibold` (600)？
2. **色阶层级验证**：
   - [ ] 弹窗容器背景是否为 `#2d2d2d`？
   - [ ] 侧边栏及内部卡片是否为 `#242424`？
   - [ ] 输入框与下拉控件底色是否为 `#1f1f1f`？
   - [ ] 描边是否统一为 `border-[0.5px] border-[#6b6b6b]` 或 `border-[#555]`？
3. **中性色阶与对比度验证**：
