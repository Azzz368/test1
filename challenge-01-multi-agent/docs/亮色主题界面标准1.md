# 亮色主题界面标准 1 / Light Theme UI Standard v1.0

> **Standard Scope & Positioning / 标准定位**
> Built upon the unified Mindverse light visual system (Figma Light Palette `379:118` & Light Image Node `218:81`), the Inter 18pt Medium typographic hierarchy, and the core Image Node design texture. This document establishes the standardized UI design and engineering specifications for console dashboards, settings modals, management drawers, and workflow cards in Light Mode across the entire application ecosystem.
> （基于 Mindverse 统一亮色系视觉规范［Figma 亮色色卡 `379:118` 与 Image 亮色核心节点 `218:81`］、Inter 18pt Medium 字体体系以及核心节点设计质感，面向全系统控制台、设置弹窗、管理面板与流程卡片的标准化亮色 UI 设计与工程实现规范。）

## 1. Core Design Principles / 核心设计原则

### 1.1 Layered Luminosity & Spatial Reduction (明度阶梯与空间减法)
- **English**: Avoid flat, washed-out all-white layouts in favor of a tactile, low-glare neutral light grey progression. Structure visual depth and spatial hierarchies through nuanced luminosity stepping (`#FFFFFF` $\to$ `#E9E9E9` $\to$ `#D9D9D9` $\to$ `#D2D2D2`) paired with ultra-thin hairline borders (`0.5px` – `1.0px`) in `#6B6B6B` / `#A3A3A3`, rather than heavy drop shadows.
- **中文说明**：摒弃缺乏层次的纯白平铺设计，采用柔和、高质感的浅灰阶梯层次。依靠精细明度递进（`#FFFFFF` $\to$ `#E9E9E9` $\to$ `#D9D9D9` $\to$ `#D2D2D2`）以及细微描边（`0.5px` ~ `1px` 的 `#6B6B6B` / `#A3A3A3`）构建层次与纵深，而非依赖浓重阴影。

### 1.2 Precision Contours & Material Consistency (精细轮廓与材质一致性)
- **English**: Strictly adhere to the **concentric stepped border-radius scale** (Outer Radius $\ge$ Inner Radius). Eliminate sharp raw corners and disjointed excessive radiuses. Utilize neutral borders (`#6b6b6b` / `#a3a3a3`) at `0.5px` stroke width to produce a crisp, precision-instrument edge finish across light surfaces (`#FFFFFF` and `#E9E9E9`), matching the dark theme's structural geometry.
- **中文说明**：严格遵循**分层递进圆角规范**（外层圆角 $\ge$ 内层圆角），杜绝尖锐生硬的直角或突兀的过大圆角。外框与核心卡片统一采用 `0.5px` 的中性灰描边（`#6b6b6b` / `#a3a3a3`），在纯白（`#FFFFFF`）与浅灰（`#E9E9E9`）表面上呈现精密仪器的利落收边质感，与暗色主题保持完全一致的几何骨架。

### 1.3 Monochrome Neutral Contrast & Controlled Highlights (纯粹黑白灰中性色与克制高亮)
- **English**: Adopt a clean, distraction-free monochrome light palette anchored on Figma palette `379:118` (`#000000`, `#6B6B6B`, `#A3A3A3`, `#D2D2D2`, `#D9D9D9`, `#E9E9E9`, `#FFFFFF`, plus warm sand accent `#CFAE8C`). Interactive primary actions rely on high-contrast solid black (`#000000`) with a subtle `#727272` border and crisp white text (`#FFFFFF`) against light surfaces (`#FFFFFF` / `#E9E9E9` / `#D9D9D9`).
- **中文说明**：全面采用基于 Figma 色卡 `379:118` 的纯粹黑白灰中性色阶（`#000000`、`#6B6B6B`、`#A3A3A3`、`#D2D2D2`、`#D9D9D9`、`#E9E9E9`、`#FFFFFF` 及暖沙金点缀色 `#CFAE8C`）。主交互按钮依靠高对比实心纯黑底（`#000000`）、`#727272` 细描边与纯白文字（`#FFFFFF`），在浅灰与纯白底色上建立清晰利落的视觉重心。

### 1.4 Typography Inheritance & Rhythmic Spacing (字体层级与排版呼吸感)
- **English**: Exclusively inherit the **Inter 18pt Medium** font family (alongside `Finlandica` for canvas node chrome where specified), anchored at weight `500` (Medium) as the core baseline and `600` (SemiBold) for structural headers. Maintain an 8-point rhythmic spacing scale (4px / 8px / 12px / 16px / 20px / 24px / 32px) to preserve consistent vertical cadences in forms and panels.
- **中文说明**：全面继承 **Inter 18pt Medium** 字体族（画布节点局部标头与下拉栏按规范兼容 `Finlandica`），字重以 `500`（Medium）为中枢基准，辅以 `600`（SemiBold）强调。采用标准网格间距（4px / 8px / 12px / 16px / 20px / 24px / 32px），表单与卡片保持清晰的垂直韵律。

## 4. Geometric Form & Border Radius Scale / 几何形态与圆角梯度标准

All interfaces must strictly follow the **concentric nested border radius progression** (同心嵌套与尺寸自适应原则), aligned with the Dark Theme standard and Figma node `218:81`:

| Radius Level (圆角层级) | Value (圆角数值) | Tailwind Class | Specifications & Applied Context / 应用组件与规范要求 |
| :--- | :--- | :--- | :--- |
| **Outer Shell (外壳层)** | `20px` (or `12px` compact Figma scale) | `rounded-[20px]` | **Modal outer containers, primary canvas nodes (Image/Video/Voice Library Node layout)**<br/>模态弹窗外壳容器、核心流程卡片外层 |
| **Inner Card (中卡片层)** | `14px` | `rounded-[14px]` | **Secondary configuration panels, voice/item tiles, dropdown menus**<br/>次级配置卡片、列表条目卡片、下拉菜单面板 |
| **Control / Nav (控件层)** | `10px` | `rounded-[10px]` | **Text inputs, textareas, select inputs, sidebar nav items**<br/>单行文本框、多行文本框、下拉选择器、侧边栏导航条目 |
| **Secondary Button (次按钮)**| `8px` | `rounded-[8px]` | **Secondary outline buttons, action chips (`Refresh`, `Rename`, `Cookie preferences`)**<br/>次级线框按钮、独立小操作项 |
| **Pill / Capsule (胶囊层)** | `9999px` | `rounded-full` | **Primary action buttons (`Run`, `Save changes`), toggle switches, avatars**<br/>主运行/保存按钮、Toggle 开关组件、圆形头像容器 |

## 七、 页面与弹窗落地 Checklist

在开发或重构亮色主题界面时，必须对照以下检查项完成审查：

1. **字体继承验证**：
   - [ ] 根容器或当前模块是否包含 `font-inter [font-family:var(--font-inter)]`？
   - [ ] 字重是否使用 `font-medium` (500) 或 `font-semibold` (600)？
2. **色阶层级验证（对齐 Figma `379:118` & `218:81`）**：
   - [ ] 主体容器/展开控制卡背景是否为 `#FFFFFF`，节点预览卡/次级面板/下拉菜单背景是否为 `#E9E9E9`？
   - [ ] 悬浮态与选中态是否使用 `#D9D9D9` / `#D2D2D2` 阶梯递进？
   - [ ] 核心外框描边是否统一为 `border-[0.5px] border-[#6b6b6b]`，次级控件描边是否为 `border-[#a3a3a3]` 或 `border-[#d2d2d2]`？
3. **中性色阶与对比度验证**：
   - [ ] 主操作按钮是否使用高对比实心黑底白字（`bg-black border border-[#727272] text-white hover:bg-[#1a1a1a]`）？
   - [ ] 主文字是否为 `#000000`，辅助说明是否为 `#6b6b6b`，占位符是否为 `#a3a3a3`？
4. **圆角阶梯验证**：
   - [ ] 模态外壳与主卡片是否为 `rounded-[20px]`？
   - [ ] 内部卡片条目是否为 `rounded-[14px]`？
   - [ ] 表单输入控件与导航项是否为 `rounded-[10px]`？
   - [ ] 次级按钮是否为 `rounded-[8px]`，主触发按钮与 Toggle 是否为 `rounded-full`？
